## Project Overview
CryptoLabX is a modular, extensible command-line toolkit designed for cryptanalysis, classical and modern cipher operations, mathematical utilities, and cryptographic attacks.

## Folder Structure
CryptoLabX/
├── classical/        # Stubs for classical ciphers (Caesar, Vigenère, Playfair, etc.)
├── attacks/          # Stubs for cryptanalytic attack routines (Frequency analysis, Brute-force)
├── math/             # Stubs for modular arithmetic, GCD, prime testing, matrix ops
├── modern/           # Stubs for modern symmetric/asymmetric algorithms (AES, RSA, ECC)
├── analysis/         # Text and statistical analysis tools
├── datasets/         # Sample text datasets for testing and benchmarking
├── outputs/          # Execution output, generated logs, and cipher results
├── docs/             # Project documentation, diagrams, and assignment briefs
├── tests/            # Unit testing and integration testing suites
├── utils/            # Helper scripts (file I/O, formatters, logging handlers)
├── main.py           # Entry point for the interactive Command Line Interface (CLI)
├── README.md         # Project documentation and setup guide
└── requirements.txt  # Project dependencies and environment requirements
